TESTS
-----
T1  Route tracking and collision freedom.
    Consumes: boxes=read_world_boxes(csv); scen=build_world(csv);
              robot=load_mir100(urdf); plat=spawn_mir100(scen,robot);
              trajLog=follow_route(plat,commandedRoute,opts), where
              commandedRoute = the global plan from plan_path when one
              exists, else the predeclared v2 route (diagnosticOnly=true).
              LOCKED SCHEMA:
              trajLog has t, x, y, yaw, wheelAngles (Nx2), waypoints,
              reachedIdx, diagnosticOnly, plannerStatus. reachedIdx,
              plannerStatus and diagnosticOnly are recorded as evidence;
              diagnosticOnly=true raises a warning in the T1 details.
              opts.maxSimTime is honored by follow_route (default 600 s).
    Measures: per-waypoint min distance of logged (x,y); footprint collision
              count computed INDEPENDENTLY by the validation module: the
              conservative footprint polygon is transformed to each logged
              (x,y,yaw) and tested against every wall box (2-D SAT, OBB vs
              polygon) using the boxes from read_world_boxes.
    PASS:   every COMMANDED waypoint captured (trajLog.reachedIdx covers
            all commanded waypoints; min-distance <= 0.15 m fallback when
            reachedIdx is absent) AND final goal within <= 0.15 m AND
            collision count == 0. The predeclared 16-waypoint v2 route
            distance is recorded as diagnostic evidence only, never gated.
            SPEC CHANGE: grading a planned path
            against the v2 route false-failed a valid plan (9/16 v2
            waypoints > 0.15 m off a valid 0.6052-inflation plan, worst
            0.658 m); T1 now grades the COMMANDED route.

T2  Clearance.
    Consumes: same trajLog and boxes as T1.
    Measures: minimum footprint-to-box distance over the whole trajectory
              (independent polygon distance; 0 on overlap) as PRIMARY value;
              clearLog=check_run_clearance(trajLog,boxes) is recorded as a
              CROSS-CHECK when available. LOCKED SCHEMA (project,
              supersedes earlier aliases): clearLog has t, minDist (Nx1),
              minOverall (scalar, m), minAt (x,y,t,box), collision. The
              runner reads minOverall (minClearance tolerated as extra alias,
              minDist derivable); NaN + note if absent.
    PASS:   primary min clearance > 0 m.

T3  Tracking error vs planned path.
    Consumes: map=build_map(boxes,res,[]) (boxes Nx7 or CSV path, NOT
              a robotScenario handle; res=0.05 m/cell default; [] =
              auto origin from wall extents);
              ok=check_map(map,boxes,res,originXY) recorded as evidence;
              path=plan_path(map,spawnWorld,goalWorld,inflateM), inflateM
              DECLARED = 0.6052 m (polygon v2); trajLog from T1.
    Measures: distance of each logged (x,y) to the nearest point on the
              planned path polyline; max and RMS.
    PASS:   max error <= 0.20 m AND RMS error <= 0.20 m.
    Empty path from plan_path is a FAIL (criterion cannot be met), not a skip.

T4  Unit/frame/wheel checks.
    Consumes: robot=load_mir100(urdfPath); report=verify_robot(robot);
              boxes=read_world_boxes(csv).
    Checks: wheelRadius, wheelSeparation, footprintRadius vs the
            declared constants above; mass gated as importedMass vs
            declaredSourceMass - both derived at RUNTIME (actual tree sum
            after load_mir100's zero-mass normalization of the 7 source
            links without <inertial>, vs the URDF inertial parse). No
            hardcoded mass constant, no subtract scheme. Also
            footprintPolygon vertex-wise vs the
            locked v2 polygon (tol 1e-6 m). LOCKED SCHEMA (project):
            report has linkCount, jointCount, massTotal, wheelRadius,
            wheelSeparation, footprintRadius, footprintPolygon, checks
            (name/value/expected/tol/pass), pass. A missing field is ERROR,
            never assumed; the module's own pass/checks are recorded as
            evidence (not gating). Boxes: Nx7, finite, positive sizes,
            |yaw| <= pi, count == 65; map->world offset consistency of
            spawn/goal/route.
    PASS:   every subcheck within tolerance.

T5  Open-loop kinematic accuracy (independent of the project modules).
    Uses differentialDriveKinematics (Robotics System Toolbox, R2019b+) with
    WheelRadius=0.0625, TrackWidth=0.4452, Euler integration at dt=0.05 s.
    SCOPE: T5 is a kinematic SELF-CONSISTENCY check of the motion model
    object. It is NOT independent physical validation of the URDF (no
    dynamics, no slip, no mass/inertia exercise).
    (a) straight: v=0.25 m/s for 8.0 s  -> expected 2.0 m,  tol 0.02 m
    (b) turn:     w=0.5 rad/s for pi/0.5 s -> expected pi rad, tol 0.02 rad
    (c) VehicleInputs='WheelSpeeds', [v/r v/r] -> expected 2.0 m, tol 0.02 m
    PASS: all three within tolerance.

T6  Sim/wall time ratio (REPORT ONLY).
    Measures: simTime = trajLog.t(end)-trajLog.t(1); wallTime around
              follow_route; ratio = sim/wall.
    PASS:   ratio measured and reported. NO threshold, by design.
            This is a single-machine indicator, NOT a realtime guarantee.
